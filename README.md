# 🛍️ Keys Store Bot — بوت متجر مفاتيح تلغرام

بوت تلغرام كامل لبيع مفاتيح التطبيقات بنظام النقاط والإحالات، بواجهتين (عربي / English)،
لوحة أدمن شاملة، سجل تعاملات مباشر لشات الإدارة، وحماية حظر مستخدمين.

> مبنّي على **aiogram 3** مع قاعدة بيانات **SQLite** بملف واحد (`data/bot.db`).

---

## ⚡ التشغيل السريع

```bash
# 1) نزّل المتطلبات (أو شغّل run.sh وهو بعمل كل شي)
pip install -r requirements.txt

# 2) شغّل البوت
python bot.py
```

أو مباشرة:

```bash
chmod +x run.sh
./run.sh
```

الإعدادات موجودة بملف `core/config.py` ويمكن تجاوزها بمتغيرات البيئة:

| المتغير | الافتراضي | الوصف |
|---|---|---|
| `BOT_TOKEN` | توكن البوت الحالي | توكن البوت من @BotFather |
| `OWNER_ID` | `7337091751` | آيدي الأونر (صلاحيات كاملة) |
| `LOG_CHAT_ID` | `-1004291296496` | شات سجل كل التعاملات |
| `SUPPORT_USERNAME` | `GIKSSEM16` | حساب الدعم الافتراضي |

## 📖 كيف يعمل البوت؟

### رحلة المستخدم الجديد
1. `/start` → إذا أول مرة، البوت يطلب **رقم تلغرام للتحقق** (زر مشاركة تلقائي أو كتابة بالصيغة الدولية) — **مرة وحدة بس**.
2. إذا دخل عبر **رابط إحالة** (`https://t.me/BOT?start=refID`) يُربط بصاحب الرابط ويحصل صاحب الرابط على **نقطة** (قابلة للتعديل) بعد إكمال التسجيل وتجاوز القنوات الإجبارية.
3. بوابة **القنوات الإجبارية**: لازم ينضم لكل القنوات المضافة ويضغط «تحقّق».
4. القائمة الرئيسية: **المتجر، حسابي، مشترياتي، الإعدادات، الدعم**.

### نظام الإحالات والخصم ⭐
- كل شخص يسجّل عبر رابط إحالتك = **+نقطة** لحسابك.
- **إذا خرج شخص دخل عبر رابطك من أي قناة إجبارية** → تُخصم نقطة منك فوراً ويوصلك إشعار فيه:
  اسم الشخص وآيديه، اسم القناة، سبب الخصم، ورصيدك الجديد.
  *(البوت لازم يكون أدمن بالقناة حتى يلتقط حدث المغادرة)*
- النقاط تُصرف من المتجر فقط.

### سجل التعاملات 📺
كل شيء يُرسل لشات السجل: مستخدم جديد (مع رقمه)، تحقق، انضمام عبر إحالة، خصومات، عمليات شراء (مع المفتاح)، حظر/فك حظر، إضافة/حذف أقسام ومنتجات ومفاتيح وقنوات، تغييرات الإعدادات، نتائج الإذاعة... إلخ.
*(لازم يكون البوت عضو/أدمن بشات السجل، وإلا ينبّه الأونر)*

### الدعم 💬
زر الدعم يحوّل المستخدم مباشرة لحساب الأونر **@GIKSSEM16** (قابل للتغيير من لوحة الأدمن).

## 🛡️ لوحة الأدمن (`/admin`)

| القسم | ماذا تفعل؟ |
|---|---|
| 📂 الأقسام | إضافة/تعديل (عربي+إنجليزي)/حذف أقسام |
| 📦 المنتجات | إضافة منتج (اسمين + سعر)، تعديل الاسم/السعر، نقل بين الأقسام، حذف |
| 🔑 مخزون المفاتيح | إضافة مفاتيح بالجملة (مفتاح بسطر)، تصدير المفاتيح ملف، تصفير المخزون |
| 📊 الإحصائيات | مستخدمين/محققين/محظورين/إحالات/نقاط متداولة/مشتريات/إيرادات/مخزون + الأكثر مبيعاً |
| 🎁 نقاط الإحالة | تعديل مكافأة الإحالة، خصم المغادرة، معرف الدعم |
| 🎨 الإيموجيات | تعديل حرف أي إيموجي + ضبط **آيدي إيموجي بريميوم** لكل عنصر + معاينة مباشرة 🧪 |
| 📢 القنوات الإجبارية | إضافة (معرف/رابط/آيدي/تحويل رسالة) وحذف |
| 👥 المستخدمون | بحث بالآيدي أو تحويل رسالة، آخر المسجلين، بطاقة كاملة، ➕➖ نقاط، 📨 رسالة خاصة، 🚫 حظر/♻️ فك حظر (مع سبب) |
| 📣 إذاعة عامة | إرسال أي محتوى لكل المستخدمين مع تقرير وصول |
| 🛡️ الأدمنز (أونر فقط) | إضافة/إزالة أدمنز |
| 💾 نسخة احتياطية (أونر فقط) | تنزيل ملف قاعدة البيانات كاملاً |

> **الصلاحيات:** كل أدمن يقدر يعمل كل شيء **ما عدا** إدارة الأدمنز (إضافة/إزالة) — هذي للأونر حصراً.

### أوامر سريعة
`/start` تشغيل • `/help` مساعدة • `/id` آيديك • `/lang` اللغة • `/admin` لوحة الأدمن

## 🎨 الإيموجيات البريميوم (مهم تقرأ)

- من لوحة الأدمن → 🎨 الإيموجيات: تقدر تعدّل **الحرف** (يظهر بالأزرار) وتضبط **آيدي بريميوم** `custom_emoji_id` لكل عنصر (28 عنصر قابل للتخصيص).
- للحصول على الآيدي: حوّل رسالة فيها الإيموجي لبوت مثل `@JSONDumpBot` وانسخ قيمة `custom_emoji_id`.
- **حدود تلغرام الرسمية:** الإيموجي البريميوم ضمن **نصوص الرسائل** تظهر فقط إذا كان **صاحب البوت مشترك Telegram Premium** (أو يملك اسم Fragment). إذا لم يتحقق الشرط، البوت يرجع تلقائياً للحرف العادي بدون أي خطأ. أزرار الأزرار داخل تلغرام تعرض الإيموجي العادي فقط (حد من تلغرام عبر Bot API).
- جرّب فوراً بزر **🧪 معاينة** بشاشة كل إيموجي.

## 🚀 النشر على منصات السحابة (Railway / Railpack...)

المستودع فيه كل شي جاهز للنشر:
- **`Dockerfile`** — Railpack بيكشفه تلقائياً ويبني الصورة.
- **`start.sh`** — بديل إذا ما استخدمت Dockerfile.

خطوات Railway:
1. **New Project → Deploy from GitHub repo** واختار المستودع.
2. ⚠️ **أهم خطوة:** تأكد إنو **الفرع المنشور يحتوي كود البوت** — إذا `main` فاضي (README بس)، ادمج الـ Pull Request أولاً أو غيّر Branch بإعدادات الخدمة إلى الفرع الصحيح.
3. بإعدادات الخدمة (Variables) حط:
   - `BOT_TOKEN` = توكن البوت
   - `OWNER_ID` = آيديك
   - `LOG_CHAT_ID` = آيدي شات السجل
   - `SUPPORT_USERNAME` = حساب الدعم (بدون @)
   - *(البوت بيقراها تلقائياً — والقيم الموجودة بـ `core/config.py` هي الاحتياطية)*
4. **Volumes:** أضف Volume واربطه بمسار `/app/data` حتى ما تنضيع قاعدة البيانات عند كل إعادة نشر.
5. البوت **Long-running polling** — ما بحتاج منفذ (Port)، سيبه بدون إعدادات شبكة.

## ⚠️ ملاحظات مهمة للتشغيل

1. **ارفع البوت أدمن في كل قناة إجبارية** — بدون هاد ما بيقدر يفحص الاشتراك ولا يلتقط المغادرة (الخصم).
2. **أضف البوت لشات السجل** `-1004291296496` كأدمن.
3. لا تشغّل نسختين من البوت بنفس التوكن (في حماية داخلية تعيد المحاولة وتحذرك باللوق).
4. **أمان التوكن:** التوكن موجود بـ `core/config.py` — إذا نشرت الكود علناً، بدّل التوكن من @BotFather واستخدم `BOT_TOKEN` كمتغير بيئة.
5. بيئة تشغيل مقترحة: أي VPS بخطوة `systemd` بسيطة أو screen/tmux.

```ini
# مثال systemd: /etc/systemd/system/keysbot.service
[Unit]
Description=Keys Store Telegram Bot
After=network.target

[Service]
WorkingDirectory=/opt/keysbot
ExecStart=/opt/keysbot/.venv/bin/python bot.py
Restart=always
RestartSec=5

[Install]
WantedBy=multi-user.target
```
